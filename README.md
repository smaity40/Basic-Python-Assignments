# Basic Python Assignments

A organized collection of basic Python exercises and assignments focusing on foundational string manipulation, loops, and pattern generation.

## 🛠️ Concepts Covered
* **String Manipulation:** Lowercase to uppercase conversions, character tracking, and counting methods.
* **String Indexing:** Reversing strings and extracting character index positions (`range()`, `enumerate()`).
* **Nested Loop Logic:** Generating custom star patterns and sequential number matrices.

## 📂 Repository Contents
* `solution.ipynb`: Complete Jupyter Notebook containing solutions, dry runs, and test outputs for all tasks.

## 🚀 How to Use
1. Clone this repository.
2. Open the `.ipynb` file in VS Code, Jupyter Lab, or Google Colab to run the Python cells.
